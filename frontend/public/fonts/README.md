# Geist

`geist-latin-variable.woff2` is the unmodified Latin variable font from
`@fontsource-variable/geist` version **5.3.0**, distributed under the included
SIL Open Font License (`Geist-OFL.txt`).

Upstream: https://vercel.com/font
Distribution: https://www.npmjs.com/package/@fontsource-variable/geist/v/5.3.0

Self-hosted to avoid runtime requests to an external font service. Hindi uses
the existing Noto Sans Devanagari dependency. No frontend framework was added.
